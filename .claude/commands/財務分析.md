# 財務分析

対象顧問先の財務データを取得し、損益・貸借・資金繰りの状況を分析してレポートを生成する。

## 実行手順

### Step 1: 作業対象の確認
以下をまとめてユーザーに確認する：
- 顧問先名
- 分析対象期間（年度 or 月次推移の場合は開始月〜終了月）
- 会計ソフト（MFクラウド会計 or freee）
- 分析の目的・知りたいこと（任意）

### Step 2: データ取得
- 試算表（損益・貸借）を取得
- 推移データが必要な場合は月次推移も取得
- MFクラウド会計 → `mfc_ca` MCP使用
- freee → `freee` MCP使用

### Step 3: 分析項目

**① 損益サマリー**
- 売上高・売上総利益・営業利益・経常利益の実績
- 前期比・前月比（データがある場合）
- 粗利率・営業利益率

**② 費用構造分析**
- 主要費用科目の金額・構成比
- 人件費比率（売上比）
- 固定費・変動費の概算分類

**③ 貸借ポイント**
- 現預金残高の水準
- 売掛金・買掛金の残高と回転日数
- 借入金残高と返済状況

**④ 月次推移（推移データがある場合）**
- 売上・利益の月次トレンド
- 季節変動パターンの有無

**⑤ 主要取引先分析**
- 売上上位取引先と金額
- 仕入上位取引先と金額

### Step 4: レポート出力

```
## 財務分析レポート：[顧問先名]（[対象期間]）

### エグゼクティブサマリー
[3〜5行で全体像を記載]

### 損益状況
[数値と分析コメント]

### 貸借状況
[数値と分析コメント]

### 注目ポイント・懸念事項
[顧問先への提言につながる気づきを箇条書き]

### データ取得日時
[日時を記載]
```

### 注意事項
- 分析結果はデータに基づく参考情報であり、税務・経営判断は税理士が最終確認する
- 「問題ない」「安全だ」等の断定的な表現は使わない
- 異常値や気になる点は必ず指摘する
