# 仕訳入力

以下の2つのモードで仕訳を登録する。

- **モードA（未仕訳データ）**: API連携済みの銀行・クレカ・ポスレジの未仕訳データに自動仕訳ルールを適用して登録
- **モードB（請求書→振替伝票）**: Googleドライブの請求書を読み取り、過去仕訳を参照して振替伝票で発生仕訳を登録

---

## 共通：作業対象の確認

作業開始時に以下をまとめて確認する：
- 顧問先名
- 対象会計期間（年月）
- モード（A：未仕訳データ / B：請求書→振替伝票 / 両方）

---

## モードA：未仕訳データの自動仕訳登録

### A-1. 未仕訳データの取得
`mfc_ca` MCPで対象期間の未仕訳取引を取得する。
取得対象：銀行口座・クレジットカード・ポスレジ・その他API連携済みデータソース。

### A-2. 自動仕訳ルールの適用と分類

取得した未仕訳データを以下の3つに分類する：

**【確実】自動登録してよい取引**
以下の条件をすべて満たすもの：
- 同一取引先・同一パターンの過去仕訳が3件以上ある
- 科目・補助科目・税区分が過去仕訳で一貫している
- 金額が過去仕訳の範囲内（大幅な外れ値でない）

対象例：
- 毎月同額のクラウドサービス利用料（通信費）
- 定期的な銀行引き落とし（水道光熱費・地代家賃等）
- POS経由の売上入金（売掛金または現金売上の回収）
- 既知の取引先からの入金（売掛金消込）

**【要確認】ユーザー判断が必要な取引**
以下のいずれかに該当するもの：
- 過去仕訳が1〜2件しかない
- 金額が過去実績から20%以上乖離している
- 新規取引先または初回取引
- 科目が過去で揺れている

**【保留】今回登録しない取引**
- 摘要が読み取れない・意味不明
- 明らかに二重計上の疑いがある
- 分割払い・按分処理が必要

### A-3. 確実分の確認リスト提示


### A-4. 登録実行
- ユーザーが承認した分のみ `mfc_ca` MCPの `postTransactions` で登録
- 要確認分は指示を受けてから登録
- 保留分は登録しない
- **登録時に必ず `tags: ["AI登録"]` を付与する**（Claude登録の証跡として残す）

## モードB：請求書→振替伝票（発生仕訳）登録

### B-1. 請求書データの取得
- GoogleドライブのフォルダURLをユーザーに確認
- フォルダ内のPDF・画像ファイルを順番に読み取る

### B-2. 請求書情報の抽出
1件ずつ以下を読み取る：
- 発行日・支払期日
- 取引先名・インボイス登録番号（適格請求書かどうか）
- 品目・摘要（細かく読む）
- 金額内訳（税抜金額・消費税額・税率・税込合計）
- 支払方法（銀行振込・クレカ・現金等）

### B-3. 過去仕訳の参照・科目推定
取引先名と品目をキーに `mfc_ca` MCPで過去振替伝票を検索し、以下を推定する：

| 推定項目 | 補足 |
|---|---|
| 借方科目 | 費用科目・資産科目等 |
| **借方補助科目** | 過去仕訳から漏れなく特定する |
| 貸方科目 | 未払金・買掛金・普通預金等 |
| **貸方補助科目** | 支払口座・カード名・取引先名等を特定する |
| 税区分 | 課税仕入10% / 8% / 非課税 / 不課税 |
| 部門 | 部門管理している場合は過去仕訳から特定 |
| 摘要 | 品目＋インボイス番号を含める |

**補助科目は必ず設定する**（未払金・買掛金・借入金等は補助科目なしで登録しない）

### B-4. 振替伝票の確認リスト提示

### B-5. 承認後に振替伝票登録
- ユーザーが承認した分のみ `mfc_ca` MCPの `postJournals` で振替伝票として登録
- **補助科目を必ず含めて登録する**（補助科目が不明な場合は登録前にユーザーに確認）
- `memo` フィールドに **GoogleドライブのファイルURL** を記載する（証票への参照リンクとして保持）
- **`tags: ["AI登録"]` を必ず付与する**（Claude登録の証跡として残す）
- 承認なしに登録しない

### B-6. 証票添付の案内

> ⚠️ 現在の mfc_ca MCP は証票ファイルの直接添付に対応していません。
> 登録後、以下のいずれかの方法で証票を紐付けてください。

**方法①：MFクラウド会計の画面から手動添付（確実）**
1. MFクラウド会計にログイン
2. 登録した仕訳を開く
3. 「証票を添付」ボタンからPDF・画像をアップロード

**方法②：memoフィールドのGoogleドライブURLで代替管理**
- MCP登録時に `memo` へファイルURLを記載済み
- 電子帳簿保存法対応としては方法①の画面添付が推奨

登録完了後に以下のメッセージを表示する：
```
📎 証票添付リスト：[N]件

以下の仕訳はMFの画面から証票の手動添付をお願いします。
| No. | 取引日 | 取引先 | ファイル名 | MFメモ欄のURL |
|---|---|---|---|---|
| 1 | 06/01 | ○○株式会社 | invoice_0601.pdf | [GoogleドライブURL] |
```

## 共通注意事項

- 補助科目が不明な場合は**推測で登録しない**。必ずユーザーに確認する
- インボイス登録番号が確認できない場合はユーザーに確認する（仕入税額控除に影響）
- 適格請求書でない場合は税区分を「課税仕入（80%控除）」等に変更する必要があることを案内する
- 1件でも不明点がある場合は、その件だけ保留にして他を先に登録する
- 登録済み取引と二重にならないよう、登録前に既存仕訳を確認する
- **証票添付は電子帳簿保存法の要件**。MF画面での手動添付を必ず促す
