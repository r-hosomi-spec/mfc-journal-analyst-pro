# 共通税区分・勘定科目ルール

## 消費税区分（MFインポートCSV用コード）

| コード（CSV記載値） | 区分名 | 主な使用場面 |
|---------------------|--------|-------------|
| `課税売上10%` | 課税売上（標準税率） | 一般的な売上 |
| `課税売上8%` | 課税売上（軽減税率） | 食料品・新聞等の売上 |
| `課税仕入10%` | 課税仕入（標準税率） | 一般的な経費・仕入 |
| `課税仕入8%` | 課税仕入（軽減税率） | 食料品・新聞等の仕入 |
| `非課税売上` | 非課税売上 | 土地売却・受取利子等 |
| `非課税仕入` | 非課税仕入 | 給与・保険料・土地購入等 |
| `対象外` | 課税対象外 | 預り金・振替・資本取引等 |
| `免税売上` | 輸出免税売上 | 輸出取引 |

## インボイス制度対応（2023年10月〜）

### 経過措置控除割合
| 期間 | 仕入税額控除割合 | 適用条件 |
|------|----------------|---------|
| 2023/10/1 〜 2026/9/30 | **80%控除** | 適格請求書発行事業者以外からの仕入 |
| 2026/10/1 〜 2029/9/30 | **50%控除** | 同上 |
| 2029/10/1 〜 | **0%控除** | 同上（控除不可） |

### インボイス対応の判断フロー
1. 外注費・支払手数料等の課税仕入 → 相手方のインボイス登録番号を確認
2. 登録番号あり → 通常通り全額仕入税額控除
3. 登録番号なし・免税事業者 → 経過措置の割合で控除、または要確認リストへ
4. 3万円未満の少額取引 → 帳簿のみで控除可（特例）

### 登録番号未確認の場合の処理
- **要確認リストに追加**し、「インボイス登録番号の確認が必要」と記載する。
- 仕訳を確定させない（自動で80%控除にするなど推論しない）。

## 会計処理方式の確認

税抜処理と税込処理でMFへの登録方法が異なります。

| 処理方式 | 税区分の扱い | 消費税仕訳 |
|---------|------------|-----------|
| **税抜処理** | 仕訳に消費税区分を設定、MFが自動計算 | 仮払/仮受消費税が自動生成 |
| **税込処理** | 金額に消費税込で入力 | 決算時に消費税仕訳を別途計上 |

**クライアントの処理方式が不明な場合は、先に確認してから仕訳を行う。**
既存スクリプト `scripts/load_journals.py` の `apply_tax_inclusive()` 関数を参照。
