## Chatwork報告文テンプレート

### 月次報告（基本形）

```
[info][title]【○○株式会社】○月度 月次報告[/title]
いつもお世話になっております。○○税理士事務所の○○です。

○月度の月次処理が完了しましたのでご報告いたします。

【今月のポイント】
・

【宿題事項・確認のお願い】
・

【次回面談のご案内】
日時: ○月○日（○）○○:○○〜
場所 / 方法: 

ご不明点がございましたら、お気軽にご連絡ください。
よろしくお願いいたします。
[/info]
```

**使い方のガイド:**
- 「今月のポイント」: 売上・利益の増減トレンド、注目すべき数値変動を2〜3点に絞る
- 「宿題事項」: クライアントへのアクション依頼のみ記載（不明取引の確認、書類提供依頼等）
- 丁寧かつ簡潔に。箇条書き推奨。

## テンプレート使用ガイドライン

### Chatwork報告文を生成するときのルール
1. クライアント名・担当者名・日付を必ず埋める
2. 数値は根拠を持って記載（試算表の該当行を参照）
3. 宿題事項は「クライアントにお願いすること」のみ。事務所側の作業は含めない
4. 文体: 丁寧体（です・ます）、過度な敬語は避けシンプルに

### 議事録を作成するときのルール
1. 前回議事録ファイルを先に読み込み、宿題事項の状況を確認してから作成する
2. 「注目した取引」は会計処理で出た要確認リストと連動させる
3. ファイルは `minutes/YYYYMM_クライアント名.md` の命名規則で保存する

### 面談準備シートを作成するときのルール
1. 業界動向はWebSearchで最新情報を検索して埋める
2. 前回議事録を必ず参照し、持越し宿題の状況を記入する
3. 数値サマリーは `accounting/output/` の最新試算表から取得する
