# 会計処理 — 追加ルール

> このファイルは `accounting/` ディレクトリで作業中に自動的に加算されます。
> ルートの `CLAUDE.md` および参照ファイル（`@.claude/rules/tax_common.md`）との組み合わせで機能します。

---

## 対象業務

- マネーフォワード（MF）クラウド会計向け仕訳帳・振替伝票インポートCSVの作成
- 銀行明細・クレジットカード明細の仕訳変換
- 月次試算表の集計・分析

---

## MF仕訳帳インポートCSV 列仕様

### 仕訳帳形式（journalcsv）

| 列名 | 型 | 必須 | 備考 |
|------|----|------|------|
| 取引No | 整数 | 任意 | 複合仕訳は同一番号を使用 |
| 取引日 | 日付 | 必須 | YYYY/MM/DD形式 |
| 借方勘定科目 | 文字列 | 必須 | MFの勘定科目名と完全一致 |
| 借方補助科目 | 文字列 | 任意 | |
| 借方部門 | 文字列 | 任意 | |
| 借方税区分 | 文字列 | 必須 | `@.claude/rules/tax_common.md` 参照 |
| 借方金額 | 整数 | 必須 | カンマなし、税込または税抜 |
| 借方税額 | 整数 | 任意 | 税抜処理時に明示する場合 |
| 貸方勘定科目 | 文字列 | 必須 | |
| 貸方補助科目 | 文字列 | 任意 | |
| 貸方部門 | 文字列 | 任意 | |
| 貸方税区分 | 文字列 | 必須 | |
| 貸方金額 | 整数 | 必須 | |
| 貸方税額 | 整数 | 任意 | |
| 摘要 | 文字列 | 任意 | 取引の内容、相手先名等を記載推奨 |
| 仕訳メモ | 文字列 | 任意 | 不明点・確認事項のメモとして活用 |

### 振替伝票形式（transfer_csv）

借方・貸方を行ごとに分けて記載する形式。複合仕訳に向く。
列仕様は仕訳帳形式に準じるが、MF公式の最新仕様を必ず確認すること。

## 仕訳作成の手順

1. **取引データの確認**: 明細・領収書・請求書から取引内容を把握する
2. **税処理方式の確認**: クライアントが税抜処理か税込処理かを確認（不明なら要確認リスト）
3. **勘定科目・税区分の選定**: `@.claude/rules/tax_common.md` の組合せ表を参照
4. **インボイス確認**: 外注費・支払手数料等は登録番号の有無を確認
5. **曖昧取引の処理**: 意図が不明な取引は要確認リストへ（推論しない）
6. **CSV生成**: Shift-JIS (CP932)、CRLF、カンマなし整数で出力
7. **出力先**: `accounting/output/YYYYMM_クライアント名_仕訳.csv`

## よくある仕訳パターン

### 銀行引落し（口座振替）
```
取引日    | 借方           | 貸方           | 摘要
---------|---------------|---------------|-----
YYYY/MM/DD | 地代家賃/課税仕入10% | 普通預金/対象外 | ○○ビル家賃 YYYYMM分
```

### 給与支払い（複合仕訳）
```
取引No | 取引日    | 借方              | 貸方           | 摘要
------|---------|-----------------|---------------|-----
1     | YYYY/MM/DD | 給与手当/対象外     | 普通預金/対象外   | ○月給与支払
1     | YYYY/MM/DD | （なし）           | 預り金(源泉所得税)/対象外 | 同上
```

### クレジットカード引落し
```
取引日    | 借方              | 貸方           | 摘要
---------|-----------------|---------------|-----
（利用時）YYYY/MM/DD | 消耗品費/課税仕入10% | 未払金(カード会社名)/対象外 | ○○購入
（引落時）YYYY/MM/DD | 未払金(カード会社名)/対象外 | 普通預金/対象外 | カード引落し
```

## 既存スクリプトの活用

`scripts/` ディレクトリの既存コードを優先的に再利用する:

| スクリプト | 機能 | 使いどころ |
|-----------|------|----------|
| `load_journals.py` | MF仕訳データのロード・パートナー抽出 | 分析・CSV変換前処理 |
| `merge_journals.py` | ページネーション結果のマージ | 大量仕訳データ処理 |
| `parse_meisai_list.py` | 銀行明細リストのパース | 口座連携データ変換 |
| `parse_balance_match.py` | 残高照合データのパース | 残高チェック・ルールブック生成 |

## 出力ファイル管理

- 生成したCSVは `accounting/output/` に保存する
- ファイル名: `YYYYMM_クライアント名_仕訳.csv`（例: `202503_株式会社ABC_仕訳.csv`）
- 要確認リストは別ファイルで出力: `YYYYMM_クライアント名_要確認.md`
