# Chatwork報告文 — 追加ルール

> このファイルは `chatwork/` ディレクトリで作業中に自動的に加算されます。
> テンプレートは `@.claude/rules/prompt_templates.md` を参照してください。

---

## 対象業務

- 月次報告文の生成
- 宿題事項リマインダーの生成
- 決算・申告完了通知の生成
- その他クライアント向けChatworkメッセージの作成

---

## 報告文作成のルール

### 必須確認事項
1. **クライアント名・担当者名**: 正確に記入する（略称・通称で構わないが一貫させる）
2. **数値の根拠**: 試算表・会計データに基づく数値のみ記載する（推測値は「概算」と明記）
3. **宿題事項の確認**: `minutes/` の最新議事録から「次回への宿題事項」を拾う

### 記述スタイル
- **文体**: 丁寧体（です・ます調）を統一する
- **長さ**: 簡潔を優先。本文は5〜8行以内を目安とする
- **箇条書き**: 宿題事項・確認事項は箇条書きで列挙する（`・` または番号付き）
- **過度な敬語を避ける**: 「お手数ですが」程度に留める。二重敬語（`ご確認いただけますでしょうか`等）は使わない

### 宿題事項の書き方
- クライアントへのアクション依頼のみ記載する（事務所側の作業は含めない）
- 「何を」「いつまでに」を明記する
- 例: `・○○の領収書のご提出（○月○日までにお願いいたします）`

## Chatwork記法

| 記法 | 表示 | 使いどころ |
|------|------|----------|
| `[info][title]タイトル[/title]本文[/info]` | 枠囲みブロック | 月次報告・通知全般 |
| `[To:ユーザーID]` | 宛先指定 | 特定の方への連絡時 |
| `[qt]引用文[/qt]` | 引用 | 前の発言への返信時 |
| `[code]コード[/code]` | コード表示 | 数値表・リスト等 |

**基本構造:**
```
[info][title]【クライアント名】件名[/title]
（本文）
[/info]
```

## テンプレートの選択ガイド

| 状況 | 使用テンプレート |
|------|---------------|
| 月次処理完了後の定期報告 | 月次報告（基本形） |
| 回答・書類が届いていない | 宿題事項リマインダー |
| 決算・法人税申告完了 | 決算・申告完了通知 |

テンプレート本文: `@.claude/rules/prompt_templates.md` の「Chatwork報告文テンプレート」を参照。

---

## 出力形式

- 生成した報告文はそのままChatworkに貼り付けられる形式で出力する
- ファイルへの保存は不要（ユーザーが直接コピーして使用）
- 複数パターンが必要な場合は番号付きで並べて出力する（「パターン①（簡潔版）」等）
